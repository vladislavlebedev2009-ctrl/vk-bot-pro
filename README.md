# VK BOT PRO 2.0

Автономный VK-бот для «Клуба имени Иосифа Сталина» (Long Poll, без веб-панели)
с попутным Discord-ботом (JDA, slash-команды). Обе платформы работают с одной
базой, званиями и правами.

Java 17+, SQLite, VK Long Poll API, Discord JDA.

---

## Настройка

1. Скопируйте `.env.example` в `.env` и заполните:

```
VK_TOKEN=токен сообщества VK
VK_GROUP_ID=ID группы
VK_PATRON_ID=VK ID владельца (Вождь клуба)

# Discord (опционально):
DISCORD_ENABLED=false
DISCORD_TOKEN=токен Discord-бота
DISCORD_GUILD_ID=ID сервера Discord
```

2. Соберите проект:

```
mvn clean package
```

3. Запустите бота:

```
java -jar target/vk-bot-pro-1.0-SNAPSHOT.jar
```

Дополнительные переменные окружения (пауза между повторным запуском
одной команды):

```
VK_COMMAND_COOLDOWN_SEC=3        # обычный пользователь
VK_ADMIN_COMMAND_COOLDOWN_SEC=1  # администраторы
```

## База данных (SQLite)

- `bot.db` — пользователи, звания, баланс, репутация, наказания, журнал.
- Файл создаётся автоматически при первом запуске (путь задаётся в `.env`,
  переменная `VK_DB_PATH`).
- Таблицы: `users`, `chats`, `punishments`, `audit_log`, `rep_changes`,
  `balance_history`, `account_links` (связка VK ↔ Discord, 1:1 в обе стороны).

Логирование происходит в `bot-log.txt`. Пароли и токены не логируются.

## Команды бота

Префикс по умолчанию — `/`. Команды выполняются в чате сообщества.

| Команда | Назначение | Права |
| --- | --- | --- |
| `/start`, `/register` | Регистрация (имя + позывной), после — звание «Кандидат» | все |
| `/help` | Справка по вашим правам | все |
| `/ping` | Проверка доступности бота | все |
| `/probe` | Пробив информации о пользователе | все |
| `/profile @id`, `/me`, `/myinfo`, `/info` | Профиль (свой или другого участника) | все |
| `/rank` | Твоё звание | все |
| `/ranks` | Список всех званий клуба | все |
| `/balance` | Твой баланс | все |
| `/pay @user <сумма>` | Перевод баланса | все |
| `/rep`, `/rep +@user`, `/rep -@user` | Начислить/снять репутацию | не сам себе |
| `/top`, `/toprep`, `/topbalance` | Рейтинг: репутация, репутация, баланс | все |
| `/top [rep\|balance\|messages]` | Рейтинг по выбранной метрике | все |
| `/connect` | Подключить бота к текущей беседе | все |
| `/disconnect` | Отключить бота от беседы | только Вождь клуба |
| `/users [страница] [фильтр] [sort:ключ]` | Список участников | все |
| `/setrank @user <ранг \| уровень>` | Смена звания (название или 1-10) | с уровня 6 |
| `/warn @user <причина>` | Предупреждение | с уровня 4 |
| `/unwarn @user` | Снять последнее предупреждение | с уровня 4 |
| `/mute @user <длительность> <причина>` | Мут (минуты или 30m, 2h, 1d); сообщения замьюченного удаляются | с уровня 4 |
| `/unmute @user` | Снять мут | с уровня 4 |
| `/ban @user <причина>` | Бан (исключение из беседы) | с уровня 4 |
| `/unban @user` | Снять бан | с уровня 4 |
| `/history [@user]`, `/audit` | Журнал действий системы и история пользователя | с уровня 4 |
| `/post`, `/publish` | Публикация записи на стене сообщества | с уровня 7 |
| `/stats` | Статистика клуба (участники, репутация, баланс, звания) | с уровня 8 |
| `/addbot` | Инструкция по добавлению бота в беседу | с уровня 8 |

`/users` поддерживает фильтры `online`, `banned`, `muted`, `active`,
`rank:<название>`, сортировку `sort:name|rank|messages|rep|balance|registered|activity`,
поиск по имени/позывному/ID (просто текстом) и пагинацию номером страницы.
По умолчанию участники отсортированы по званию (высшее первым).

Все действия администрации фиксируются в журнале `audit_log`
(кто, что, над кем, результат OK/DENIED/NO_ACTIVE).

## Иерархия званий и права

Чем выше уровень, тем выше звание.

| Звание | Ступень | Уровень |
| --- | --- | --- |
| Вождь клуба | X | 10 |
| Первый секретарь | IX | 9 |
| Член Президиума | VIII | 8 |
| Народный комиссар | VII | 7 |
| Старший инструктор | VI | 6 |
| Командир отряда | V | 5 |
| Организатор | IV | 4 |
| Активист | III | 3 |
| Товарищ | II | 2 |
| Кандидат | I | 1 |

Пороги прав (по уровню звания):

- **1 (Кандидат+):** профиль, репутация, экономика, `/users`, `/connect`,
  `/rank`, `/ranks`, `/top`, `/help`;
- **4 (Организатор+):** модерация `/ban /unban /warn /unwarn /mute /unmute`
  и `/history` (журнал, включая `/audit`);
- **6 (Старший инструктор+):** `/setrank`;
- **7 (Народный комиссар+):** `/post`, `/publish`;
- **8 (Член Президиума+):** `/stats`, `/addbot`;
- **Вождь клуба:** все права.

Правила: администратор не может наказать или изменить звание самому себе,
Вождь клуба неуязвим для наказаний и смены звания, наказать или изменить
звание пользователю с рангом выше или равным своему нельзя. Все проверки
централизованы в `AccessControlService`.

## Discord-бот

Попутный сервис: включает `DISCORD_ENABLED=true`, токен и ID сервера бот
берёт только из окружения (`DISCORD_TOKEN`, `DISCORD_GUILD_ID`). При любой
ошибке Discord (нет токена, неверный токен, нет связи с Gateway, rate limit)
VK-бот продолжает работать — запись об этом уходит в `bot-log.txt`.
Интент Message Content не используется, только slash-команды.

### Привязка профиля

Discord ID и VK ID это разные идентификаторы, поэтому их нужно связать
(строго 1:1 в обе стороны, одноразово):

1. В VK-боте выполните `/link` — бот выдаст одноразовый код (действует 15 минут).
2. В Discord выполните `/link <код>` — Discord привяжется к вашему VK-профилю.
3. Повторная привязка невозможна: у одного VK и одного Discord только один общий профиль.

### Slash-команды

Все команды работают с общей базой VK-бота, права проверяются по званию клуба.

| Команда | Назначение | Права |
| --- | --- | --- |
| `/help` | Справка по командам | все |
| `/register` | Статус регистрации твоего профиля | все |
| `/link <код>` | Привязать Discord к VK-профилю | все |
| `/profile` | Карточка твоего профиля | с 1 уровня |
| `/rank` | Твоё звание | с 1 уровня |
| `/ranks` | Все звания клуба | с 1 уровня |
| `/balance` | Твой баланс | с 1 уровня |
| `/top` | TOP по репутации | с 1 уровня |
| `/history` | История и журнал действий по твоему профилю | с 4 уровня |
| `/stats` | Статистика клуба | с 8 уровня |

## Структура проекта

```
src/bot
├── Main.java                  Точка входа (Long Poll + Discord)
├── config/                    BotConfig, Environment (чтение .env)
├── model/                     User, Rank, Punishment, AuditEntry и т.д.
├── api/                       VkApi (вызовы VK API)
├── database/                  SQLite-репозитории (User, Chat, Punishment,
│                              Audit, LinkRepository и др.)
├── discord/                   DiscordBotService (JDA) и обработчик slash-команд
├── service/                   Registration, MessageProcessing, LinkService,
│                              RateLimiter, PunishmentService, AccessControl,
│                              RankService, Logger, VkCommunityService
├── util/                      Text (форматирование чисел и дат)
└── command/                   CommandDispatcher, CommandContext и команды
```

## Диагностика

- Бот не стартует: проверьте `VK_TOKEN` и сетевой доступ к VK.
- Ошибки — в `bot-log.txt`.
- При изменении БД сделайте резервную копию `bot.db` перед запуском.
